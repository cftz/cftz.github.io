# Comfort Zone

A small, dependency-free company website. Plain HTML and CSS, with locally hosted Work Sans and a decorative SVG.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000/.

## Deployment

GitHub Pages publishes the root of the `main` branch. No build step, JavaScript, third-party embeds, analytics, forms, or application backend is required. Relative asset paths also support project-site deployment.

The font license is included in `assets/fonts/OFL.txt`.

Custom domains and DNS are managed separately by the owner. Do not add a CNAME file as part of normal website updates.
